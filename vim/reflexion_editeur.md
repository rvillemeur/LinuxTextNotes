# choix d'un éditeur et d'un environnement

## point fort et point faible de VI

+ raccourcis clavier puissant pour l'edition de texte
+ possibilité de personnaliser l'éditeur par programmation
+ Interface claire et lisible, centrée sur l'édition de texte.

- ne peux pas traiter les images
- customisation graphique impossible, il faut jouer sur les polices de 
    caractères.
- syntaxe de programmation absconte.

## environnement idéal

* possibilité d'éditer du texte long de façon aussi efficace que dans VI.
* pour le texte court, un éditeur plus traditionnel peut suffire. 
* possibilité d'aménager l'environnement graphique pour le personnaliser selon 
    les besoins
* syntaxe de développpement simple, type smalltalk.
* colorisation syntaxique
* voir les éléments avec un affichage avancé:
    ** écrire le texte en Markdown
    ** afficher le text en RTF (Rich Text Format)
* possibilité de mixer le code et la documentation
* Flexibilité dans l'interface (type pharo).


## point de réflexion sur GToolkit

* environnement intégré
* personnalisation du browser, des inspecteur
* environnement visuellement attrayant.
